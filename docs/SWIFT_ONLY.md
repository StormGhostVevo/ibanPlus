# SWIFT-only countries (not supported)

These countries have no local payout rail in the Airwallex payout requirements doc (26/10/2026), so the only way to pay them is an international SWIFT transfer. The library does not support them: `getConfiguredCountries()` leaves them out and `validateBankDetails` rejects them.
